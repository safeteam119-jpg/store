# 2026 직원 건강관리 설문조사

매장용 / 본사용 설문 사이트. 내용과 구성은 동일하고, 진행한 프로그램 종류(질문 3, 4번의 세부 항목)만 다르게 구성합니다.
현재는 **매장용(store/)** 이 먼저 완성되어 있습니다.

## 구조

```
store/
  index.html        # 매장용 설문 페이지 (깃허브 Pages로 배포)
apps-script/
  Code.gs           # 구글 스프레드시트에 응답을 적재하는 백엔드 (Apps Script 웹앱)
```

## 동작 방식

1. `store/index.html`은 순수 HTML/CSS/JS로 만든 정적 페이지입니다. 깃허브(GitHub Pages)에 그대로 올리면 바로 동작합니다.
2. 사용자가 설문을 제출하면 `fetch()`로 Apps Script 웹앱 URL에 결과를 전송합니다.
3. Apps Script(`Code.gs`)가 그 요청을 받아 지정한 구글 스프레드시트에 한 행씩 추가합니다.

> 기존에 주신 Apps Script 사이트(`google.script.run` 방식)는 구글이 호스팅하는 페이지 안에서만 동작하는 방식이라, 깃허브 같은 외부 정적 호스팅에서는 쓸 수 없습니다. 그래서 "웹앱으로 결과만 받는 백엔드"와 "깃허브에 올리는 설문 화면"을 분리했습니다.

## 1) Apps Script 백엔드 배포 (스프레드시트에 응답 쌓기)

1. 결과를 모을 스프레드시트 열기:
   `https://docs.google.com/spreadsheets/d/1ODz3LIxyHucAq-4L_FfZCl9RKU0w__43E3EoYRFmnkA/edit`
2. 메뉴 [확장 프로그램] → [Apps Script] 클릭
3. 기본 코드 전체 삭제 후 `apps-script/Code.gs` 내용을 그대로 붙여넣기
4. 저장 (Ctrl+S)
5. 우측 상단 [배포] → [새 배포]
   - 유형 선택(⚙️): **웹 앱**
   - 설명: 아무 이름
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **전체(Anyone)**  ← 꼭 "전체"로 설정해야 깃허브에서 로그인 없이 호출 가능합니다.
6. [배포] 클릭 → 권한 승인(본인 계정) → 생성된 **웹 앱 URL** 복사
   (`https://script.google.com/macros/s/xxxxxxxx/exec` 형태)

응답은 스프레드시트에 `매장_응답`, `본사_응답` 이름의 탭이 자동 생성되어 쌓입니다.
(기존 `gid=0` 탭 내용을 건드리지 않도록 별도 탭으로 분리했습니다. 필요하면 탭 이름/위치를 자유롭게 바꾸셔도 Code.gs 동작에는 영향 없습니다.)

## 2) 설문 페이지에 백엔드 URL 연결

`store/index.html` 파일을 열어 아래 줄을 찾습니다.

```js
const SCRIPT_URL = 'YOUR_APPS_SCRIPT_WEB_APP_URL';
```

1번에서 복사한 웹 앱 URL로 교체합니다.

```js
const SCRIPT_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

## 3) 깃허브에 배포 (GitHub Pages)

1. 깃허브에 새 저장소 생성 후 이 폴더(`store/index.html` 포함) 푸시
2. 저장소 [Settings] → [Pages]
3. Source를 **Deploy from a branch**, 브랜치는 `main`, 폴더는 `/ (root)` 또는 `/store`로 설정
   - 폴더를 root로 두면 접속 주소는 `https://<아이디>.github.io/<저장소명>/store/`
   - `store` 폴더를 Pages 루트로 지정하면 `https://<아이디>.github.io/<저장소명>/`
4. 몇 분 후 해당 주소로 접속해 테스트 제출 → 스프레드시트에 행이 추가되는지 확인

## 최종 질문 구성 (매장용, 총 7문항)

1. 올해 진행된 건강관리 활동이 본인의 건강관리 인식 및 실천에 도움이 되었다고 느끼셨습니까? (1~5점 척도, 원본 그대로)
2. **[신규]** 본인의 건강이 전년도에 비해 개선되었다고 생각하십니까? (예 / 비슷하다 / 악화되었다)
   → "예" 선택 시 하위 질문 노출: 혈당수치 / 혈압수치 / 콜레스테롤수치 / 체중감량 (중복 선택 가능)
3. 올해 진행된 보건관리 활동을 통해 회사가 직원 건강관리에 관심을 갖고 지원하고 있다고 느끼셨습니까? (1~5점 척도, 원본 2번 문항을 그대로 유지하고 순서만 뒤로 이동)
4. 올해 진행된 보건관리 활동 중 가장 만족하신 활동은 무엇입니까? (중복 선택, 원본 3번)
5. 올해 진행된 건강프로그램 중 참여하신 항목 (걷기 프로그램/그림 컨테스트 + 각 만족도, 원본 4번)
6. 이전의 HR 수기 등록 방식에 비하여 어떠케어를 통한 건강검진 결과 등록 방식에 만족하시나요? (1~5점 척도, 원본 5번)
7. 추후 참여하고 싶은 건강관리 프로그램은 무엇입니까? (원본 6번, 선택지 교체)
   1) 걷기 프로그램
   2) 다이어트 및 영양 프로그램
   3) 운동 프로그램
   4) 금주,금연 등 생활습관 프로그램
   5) 스트레스 관리 프로그램
   6) 기타 (직접 입력)

구성/디자인 톤(보라색 테마)은 원본 사이트를 그대로 따르면서, 모바일에서 보기 편하도록 카드형 UI, 큰 터치 영역, 하단 고정 제출 버튼, 상단 진행률 바를 추가했습니다.

## 본사용 사이트

본사용은 3, 4번 문항(진행한 프로그램 종류)만 다르게 구성하면 되므로, 매장용 구조가 확정되면 그대로 복제해서 `hq/index.html`로 만들면 됩니다. 어떤 프로그램 목록으로 바꿀지 알려주시면 이어서 작업하겠습니다.
