# 2026 직원 건강관리 설문조사 (매장용)

매장 직원 대상 건강관리 설문 사이트입니다.
본사용은 설문/시트/배포를 완전히 별도로 구성할 예정이라 이 저장소는 매장용만 다룹니다.

## 구조

```
index.html        # 매장용 설문 페이지 (깃허브 Pages로 배포, 저장소 루트)
apps-script/
  Code.gs          # 구글 스프레드시트에 응답을 적재하는 백엔드 (Apps Script 웹앱)
```

## 동작 방식

1. `index.html`은 순수 HTML/CSS/JS로 만든 정적 페이지입니다. 깃허브(GitHub Pages)에 그대로 올리면 바로 동작합니다.
2. 사용자가 설문을 제출하면 `fetch()`로 Apps Script 웹앱 URL에 결과를 전송합니다.
3. Apps Script(`Code.gs`)가 그 요청을 받아 지정한 구글 스프레드시트에 한 행씩 추가합니다.

> 기존에 주신 Apps Script 사이트(`google.script.run` 방식)는 구글이 호스팅하는 페이지 안에서만 동작하는 방식이라, 깃허브 같은 외부 정적 호스팅에서는 쓸 수 없습니다. 그래서 "웹앱으로 결과만 받는 백엔드"와 "깃허브에 올리는 설문 화면"을 분리했습니다.

## 1) Apps Script 백엔드 배포 (스프레드시트에 응답 쌓기)

1. 결과를 모을 스프레드시트 열기:
   `https://docs.google.com/spreadsheets/d/1ODz3LIxyHucAq-4L_FfZCl9RKU0w__43E3EoYRFmnkA/edit`
2. 메뉴 [확장 프로그램] → [Apps Script] 클릭
3. 기본 코드 전체 삭제 후 `apps-script/Code.gs` 내용을 그대로 붙여넣기
4. 저장 (Ctrl+S)
5. 우측 상단 [배포] → [새 배포]
   - 유형 선택(⚙️): **웹 앱**
   - 설명: 아무 이름
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **전체(Anyone)**  ← 꼭 "전체"로 설정해야 깃허브에서 로그인 없이 호출 가능합니다.
6. [배포] 클릭 → 권한 승인(본인 계정) → 생성된 **웹 앱 URL** 복사
   (`https://script.google.com/macros/s/xxxxxxxx/exec` 형태)

응답은 스프레드시트에 `매장_응답` 탭이 자동 생성되어 쌓입니다.
(기존 `gid=0` 탭 내용을 건드리지 않도록 별도 탭으로 분리했습니다. 필요하면 탭 이름/위치를 자유롭게 바꾸셔도 Code.gs 동작에는 영향 없습니다.)

> 현재 배포 완료: `SCRIPT_URL`이 `index.html`에 이미 반영되어 있습니다. 재배포하거나 다른 스프레드시트로 바꾸는 경우에만 URL을 다시 교체하면 됩니다.

## 2) 깃허브 배포 (GitHub Pages)

이미 `https://github.com/safeteam119-jpg/store` 에 푸시되어 있습니다. GitHub Pages만 켜면 됩니다.

1. 저장소 [Settings] → [Pages]
2. Source: **Deploy from a branch**, Branch: **main**, 폴더: **/(root)**
3. 저장하면 몇 분 후 `https://safeteam119-jpg.github.io/store/` 로 바로 접속 가능합니다.
   (`index.html`이 저장소 루트에 있어서 하위 경로 없이 바로 접속됩니다)
4. 접속해서 테스트 제출 → 스프레드시트 `매장_응답` 탭에 행이 추가되는지 확인

## 최종 질문 구성 (총 6문항)

1. 올해 진행된 건강관리 활동이 본인의 건강관리 인식 및 실천에 도움이 되었다고 느끼셨습니까? (1~5점 척도)
2. 본인의 건강이 전년도에 비해 개선되었다고 생각하십니까? (예 / 비슷하다 / 악화되었다)
   → "예" 선택 시 하위 질문 노출: 혈당수치 / 혈압수치 / 콜레스테롤수치 / 체중감량 (중복 선택 가능)
3. 올해 진행된 건강관리 활동을 통해 회사가 직원 건강관리에 관심을 갖고 지원하고 있다고 느끼셨습니까? (1~5점 척도)
4. 올해 진행된 건강관리 활동 중 가장 만족하신 활동은 무엇입니까? (중복 선택)
5. 올해 진행된 건강프로그램 중 참여하신 항목 (걷기 프로그램/그림 컨테스트 + 각 만족도)
6. 추후 참여하고 싶은 건강관리 프로그램은 무엇입니까? (중복 선택)
   1) 걷기 프로그램
   2) 다이어트 및 영양 프로그램
   3) 운동 프로그램
   4) 금주,금연 등 생활습관 프로그램
   5) 스트레스 관리 프로그램
   6) 기타 (직접 입력)

(기존 "HR 수기 등록 방식 대비 어떠케어 만족도" 문항은 삭제했습니다.)

디자인은 원형 숫자 버튼(1~5점 척도), 체크마크가 보이는 카드형 선택지, 하단 고정 제출 버튼, 상단 진행률 바로 모바일 가독성과 터치 편의성을 높였습니다.

## 본사용 사이트

본사용은 설문 내용은 유사하지만 스프레드시트, Apps Script 배포, 깃허브 저장소, 사이트 주소까지 전부 이 매장용과 **완전히 분리**해서 별도로 만듭니다. (같은 저장소의 하위 경로가 아니라 독립된 프로젝트로 구성)
